# Proyek Pengeluaran Harian

Program Python sederhana untuk mencatat, membaca, menganalisis, dan melaporkan pengeluaran harian melalui file teks.

Jalankan dari folder proyek:

```powershell
python main.py
python -m unittest discover -s tests
```

Tempat tautan pengumpulan:

- Repositori GitHub publik: isi setelah proyek diunggah.
- Video YouTube publik: isi setelah video dibuat dan diunggah.
